CONTEXT
═══════════════════════════════════════════════════════
The InvoiceApp currently tracks clients, projects, invoices, pipeline and revenue analytics.
This sprint extends it with project codes, billable time tracking, and write-offs.

Key clarifications from user:
- Project_Code = client_code + client_suffix (2-digit). Not a free-form label.
- A project can have multiple project_codes; each code covers a scope/portion of the project.
- client_code in CSV matches clients.client_code in the DB.
- (client_code + client_suffix) uniquely maps to exactly one project.
- Internal rows (e.g. 0009COM00 Company Admin, Conferences, Public Holiday) are kept — needed for future time-off/internal summaries.
- Write-offs allocate down to (project_code, person) level, not just code.
- Time import CSV format is fixed/known — no column mapping UI needed.
- Duplicate detection key: (period, emp_nbr, client_code, client_suffix).

1. NEW DB TABLES  (add to backend/db.py → init_db())
═══════════════════════════════════════════════════════

project_codes
─────────────
CREATE TABLE IF NOT EXISTS project_codes (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id     INTEGER NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    client_code    TEXT    NOT NULL,   -- matches clients.client_code
    client_suffix  TEXT    NOT NULL,   -- 2-digit suffix, e.g. '01', '07'
    name           TEXT    DEFAULT '',
    description    TEXT    DEFAULT '',
    budget_amount  REAL    DEFAULT 0.0,
    status         TEXT    DEFAULT 'Active',
    created_at     TEXT    DEFAULT (datetime('now')),
    UNIQUE(client_code, client_suffix)  -- globally unique → uniquely maps to one project
);

time_entries
────────────
CREATE TABLE IF NOT EXISTS time_entries (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_code_id INTEGER REFERENCES project_codes(id) ON DELETE SET NULL,
    project_id      INTEGER REFERENCES projects(id) ON DELETE CASCADE,
    period          TEXT    NOT NULL,  -- yyyymm, e.g. '202206'
    emp_nbr         TEXT    NOT NULL,
    consultant      TEXT    NOT NULL,
    client_code     TEXT    NOT NULL,
    client_suffix   TEXT    NOT NULL,
    total_hours     REAL    DEFAULT 0.0,
    non_z_hours     REAL    DEFAULT 0.0,  -- billable hours
    z_hours         REAL    DEFAULT 0.0,  -- internal hours (time-off, admin, etc.)
    total_charges   REAL    DEFAULT 0.0,
    non_z_charges   REAL    DEFAULT 0.0,  -- billable charges
    z_charges       REAL    DEFAULT 0.0,  -- internal charges
    description     TEXT    DEFAULT '',
    batch_ref       TEXT    DEFAULT '',   -- import filename/timestamp for batch delete
    created_at      TEXT    DEFAULT (datetime('now')),
    UNIQUE(period, emp_nbr, client_code, client_suffix)  -- duplicate guard
);

write_offs
──────────
CREATE TABLE IF NOT EXISTS write_offs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id      INTEGER NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    project_code_id INTEGER REFERENCES project_codes(id) ON DELETE SET NULL,
    emp_nbr         TEXT    DEFAULT '',   -- person allocation (empty = project-level only)
    consultant      TEXT    DEFAULT '',
    amount          REAL    NOT NULL,
    reason          TEXT    NOT NULL,
    notes           TEXT    DEFAULT '',
    allocation_type TEXT    DEFAULT 'project',  -- 'project' (auto pro-rata) | 'adhoc'
    reversed        INTEGER DEFAULT 0,
    reversed_reason TEXT    DEFAULT '',
    reversed_at     TEXT    DEFAULT '',
    created_at      TEXT    DEFAULT (datetime('now'))
);

3. NEW DB FUNCTIONS  (backend/db.py)
═══════════════════════════════════════════════════════

Project codes:
  get_project_codes(project_id=None, status=None) → list[ProjectCode]
  get_project_code_by_keys(client_code, client_suffix) → ProjectCode | None
  add_project_code(project_id, client_code, client_suffix, name, description, budget_amount, status) → int
  update_project_code(code_id, name, description, budget_amount, status) → None
  delete_project_code(code_id) → None  (guard: fail if time entries exist)

Time entries:
  add_time_entries_bulk(entries: list[dict]) → dict  — returns {inserted, skipped, unmatched}
    Logic: for each row, look up project_code by (client_code, client_suffix);
           if not found → unmatched (store row but project_code_id = NULL, flag in result);
           if duplicate (period+emp_nbr+client_code+client_suffix) → skipped.
  get_time_entries(project_id=None, project_code_id=None, period_from=None, period_to=None,
                   emp_nbr=None, include_internal=True) → list[TimeEntry]
  delete_time_batch(batch_ref: str) → int
  get_time_summary(project_id: int) → list[dict]
    Per-code rollup: {client_code, client_suffix, name, budget_amount,
                      total_hours, non_z_hours, non_z_charges, write_off_amount, net_charges}

Write-offs:
  add_write_off_project(project_id, amount, reason, notes) → list[int]
    Allocates pro-rata by non_z_charges across (project_code, consultant) pairs;
    creates one write_offs row per (code, person) combination.
  add_write_off_adhoc(project_id, project_code_id, emp_nbr, consultant, amount, reason, notes) → int
  get_write_offs(project_id=None, include_reversed=False) → list[WriteOff]
  reverse_write_off(write_off_id, reason) → None
